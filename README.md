# Uzquiz — O'zbekcha viktorina (MVP 1.1)

Live: https://alokhon99.github.io/uzquiz/ · Question editor: https://alokhon99.github.io/uzquiz/admin.html

Mobile-first PWA quiz game in Uzbek: 6 rounds × 7 questions. No dependencies, no build step.

## Run
```bash
node serve.mjs 5173
```
Open http://localhost:5173 (use the browser's phone/device mode, or open it from a phone on the same network).

## Test
```bash
node tests/run-tests.mjs
```
E2E suites run inside the open page (served by `serve.mjs` under `/__tests/`):
- game: `const m = await import('/__tests/e2e.js'); await m.run('full')`
- editor (on `admin.html`, publishing mocked): `const m = await import('/__tests/admin-e2e.js'); await m.run('edit')`

## Structure
| Path | What |
|---|---|
| `app/index.html`, `app/css/styles.css` | Shell & design |

| `docs/05-foydalanuvchi-qollanmasi.md` | User manual (Uzbek) |

## Publishing question changes
The editor commits `questions.js` straight to `main` and `gh-pages` through the GitHub API, so run `git pull` before working locally.
To deploy code changes: `git push origin main`, then `git subtree split --prefix app -b gh-pages && git push origin gh-pages`.
